# Design Decisions

## Purpose

В этой папке хранится всё, что относится к дизайну публичного сайта.

## Structure

- inspiration/ — скриншоты понравившихся сайтов
- screenshots/ — скриншоты текущей реализации
- logo/ — логотип, favicon, иконки приложения

## Rules

1. Не искать "идеальный" сайт.
2. Собирать только те решения, которые действительно хочется повторить.
3. Каждый скриншот называть осмысленно:
   - writer-home-01.png
   - editorial-layout-02.png
   - typography-03.png
4. Если сайт особенно понравился — добавить ссылку и краткий комментарий:
   - что именно понравилось;
   - что хочется повторить;
   - что повторять не нужно.

## Cursor

Cursor может использовать содержимое этой папки как источник вдохновения при разработке дизайна.

Приоритет:

1. Референсы из design/inspiration/
2. Скриншоты текущего сайта
3. Затем любые собственные предложения

**Отступы hero (актуальные px из Figma):** единственный текстовый source of truth — секция **«Hero layout (desktop anchors)»** в `docs/website-design-system.md`. При смене отступа в коде — сразу править ту таблицу.

Главное правило:
Не ломать существующую функциональность MediaOS. Меняется только внешний вид публичной части сайта.
